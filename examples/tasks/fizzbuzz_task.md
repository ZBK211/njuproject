# Demo task

In the demo workspace, implement `fizzbuzz(n)` in `fizzbuzz.py`.

Requirements:

- Return a list of strings for integers from 1 through `n`.
- Multiples of 3 become `Fizz`, multiples of 5 become `Buzz`, and multiples of both become `FizzBuzz`.
- Non-positive `n` returns an empty list.
- Run the tests after editing and report the result.
